
# Project Details – AWS Café Disaster Recovery

## 1. Project Background

This project was completed as part of my TAFE NSW Cloud Architecture studies.

The scenario involves designing a disaster recovery solution for a café business that relies on online ordering, customer records, inventory management and point-of-sale systems.

## 2. Project Objective

The objective was to design a cloud-based disaster recovery solution to improve business continuity and reduce downtime during unexpected disruptions.

## 3. Proposed AWS Architecture

The proposed design uses a Warm Standby approach across two AWS regions:

- Primary Region: Sydney (ap-southeast-2)
- Secondary Region: Melbourne (ap-southeast-4)

## 4. AWS Services Considered

- Amazon EC2
- Amazon RDS
- Amazon S3
- Amazon Route 53
- Amazon CloudWatch
- AWS IAM
- AWS CloudFormation
- AWS Lambda

## 5. Disaster Scenarios Considered

- AWS regional outage
- Cyberattack or malware
- Application failure
- Data loss or corruption

## 6. Skills Demonstrated

- AWS cloud architecture concepts
- Disaster recovery planning
- High availability and business continuity
- Backup and recovery strategies
- Risk assessment
- Technical documentation

## 7. Project Status

This is an educational architecture and disaster recovery planning project. The proposed multi-region architecture was designed as part of my TAFE studies; it is not a claim of a fully deployed production environment.
